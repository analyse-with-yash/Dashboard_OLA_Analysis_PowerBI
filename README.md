# 🚖 Ola Ride Booking Analysis Dashboard

An interactive **Power BI dashboard** built to analyze **99K+ Ola ride booking records** and generate meaningful business insights through data visualization and reporting.

## 📌 Project Overview

This project focuses on analyzing Ola ride booking data to track booking performance, revenue trends, cancellations, customer behaviour, payment preferences, and vehicle-wise performance.

The dashboard transforms raw ride data into actionable insights for better business decision-making.



## 📊 Key Insights

- **Total Bookings:** 99K+
- **Total Booking Value:** ₹28.53M
- **Booking Success Rate:** 61.73%
- **Cancellation Rate:** 11.49%

- Wallet payments contributed the highest revenue
- Prime Sedan showed strong booking performance
- Customer ratings remained consistently positive across all vehicle types



## 🔍 Dashboard Features

### **Overall Analysis**
- Total bookings and booking value tracking
- Booking status breakdown
- Ride value trends over time

### **Vehicle Type Analysis**
- Booking performance by vehicle category
- Distance travelled comparison
- Revenue contribution by vehicle type

### **Revenue Analysis**
- Revenue by payment method
- Ride distance trend analysis
- Top customer booking value insights

### **Cancellation Analysis**
- Customer cancellation reasons
- Driver cancellation reasons
- Cancellation rate metrics

### **Ratings Analysis**
- Vehicle-wise customer ratings
- Service quality comparison
